# Praca Magisterska

Repozytorium zawiera materiały związane z pracą magisterską.

## Struktura repozytorium

- **documents/** – materiały źródłowe  
- **graphics/** – grafiki, diagramy i wykresy wykorzystywane w pracy  
- **masters_project/** – projekt w SystemVerilog na vivado 2024.2  
- **python_imp/** – implementacje i skrypty w Pythonie  
- **systemVerilog_src/** – źródła w SystemVerilog (moduły)
